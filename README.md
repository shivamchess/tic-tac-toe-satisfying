# Ultra-Satisfying Tic Tac Toe

A premium Android Tic Tac Toe game built with **Jetpack Compose** focusing on beautiful animations, fluid interactions, and haptic feedback.

## Features
- **Smooth Animations**: Animated X/O drawing, score transitions, and a sweeping winning line.
- **Haptic Feedback**: Feels great to play with satisfying physical responses on moves and game ends.
- **Material 3 Design**: Deep navy dark theme with vibrant coral/mint accents.
- **State Management**: Clean architecture using ViewModel and StateFlow.
- **CI/CD Built-in**: GitHub Actions workflow included for automated debug APK builds.

## How to use GitHub Actions
1. Push this repository to GitHub.
2. Go to the **Actions** tab in your repository.
3. The workflow `Build Android APK` will automatically run.
4. Once completed, download the `TicTacToe-debug` artifact at the bottom of the run summary.
